= Общие сведения

Файлы в системе {dv} имеют две составляющие: атрибутивную и бинарную. Бинарная часть может храниться в БД {dv} или во внешнем хранилище файловой системы, хранилище внешней БД или FileStream внешней БД. Коннектор к хранилищу S3 содержит набор системных компонентов, расширение для серверной консоли, обеспечивающее работу с внешним хранилищем в {dv}.

Коннектор к файловому хранилищу S3 предназначен для применения в организациях, эксплуатирующих систему {dv}.
