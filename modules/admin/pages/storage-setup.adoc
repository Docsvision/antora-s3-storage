= Настройка хранилища S3 в {dv}

. Установите хранилище S3 на выделенном сервере согласно xref:install.adoc[инструкции].
. Зайдите в web-интерфейс S3 по адресу `\http://server-name:9001` под учётной записью администратора и создайте бакеты с названиями `archive` и `primary`.
. Скопируйте следующие файлы в каталог `/usr/lib/docsvision/common/` на сервере {dv}:
+
* `AWSSDK.Core.dll`
* `AWSSDK.S3.dll`
* `S3StorageServer.dll`
* `S3StorageServer.pdb`
* `S3StorageServer.deps.json`
* `credintails.txt`
+
. В файле `credintails.txt` укажите действующий адрес сервера S3.
. Скопируйте библиотеку `S3StorageProvider.dll` на сервер приложений на сервер с программой {cns} в каталог `/S3/` в корне системного раздела (диск `C:/`).
. Намашине с Windows запустите {cns}, перейдите к разделу menu:Базы данных[Настройка > Внешние хранилища], создайте новое хранилище, в качестве типа выберите *_Добавить из сборки..._* и выберите укажите `S3StorageProvider.dll`. После добавления внешнего хранилища должен появиться тип `S3 storage`.
. Перезапустите {sss-new}.
. Настройте использование внешнего хранилища S3 по инструкции, приведённой в разделе "xref:platform:console:storage-setup.adoc[]".
+
.Настройка использования внешнего хранилища S3
image::storage-setup.png[Настройка использования внешнего хранилища S3]
+
. В свойствах базы данных, на вкладке _Внешние хранилища_ выберите тип *_S3 storage_*.
. После сохранения настроек, файлы будут вытесняться в хранилище файлов. Файлы будут отображаться в web-интерфейсе S3, в подкаталогах, отсортированные по дате создания файла.
+
.Интерфейс хранилища S3 с вытеснёнными файлами
image::s3-interface.png[Интерфейс хранилища S3 с вытеснёнными файлами]
+
Имя файла в web-интерфейсе будет начинаться с его ID.
